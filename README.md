# hdt-bg-helper

Hearthstone Deck Tracker（HDT）的酒馆战棋辅助插件：个人对局数据采集 + 基于战斗模拟的战力分位评估 + 局内显示与赛后复盘。

目标是帮助玩家本人提升决策与复盘质量，不做自动操作。
