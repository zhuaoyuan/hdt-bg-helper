- **状态：** review（第 8 节已由所有者确认。Q-020 已关闭：伤害被上限截断，\(\alpha=\beta=0\)，不补伤害列；选点退回最后 3 场对名次。公式不变）
- **任务：** 主线外。活的战力计算改为本方案的 \(s\)（ADR-0016），不再与 \(P_w+0.5P_t\) 并列
- **作者 / 日期：** agent / 2026-10-11
- **相关：** ADR-0016、ADR-0017、ADR-0003、ADR-0011；`facts/strength-validity-p3t4.md`；Q-020

## 1. 目标与非目标

**目标：** 用胜/平比例、回合、胜时造成伤害、败时受到伤害重写一对场面的得分 \(s\)。权重是回合的低维函数。最后 3 场以外，分位应与保血一致（对同阶段阵容的平均掉血更低）。最后 3 场同时看名次和保血。搜完后的 \(s\) **替换**现在的战力计算。

| 做完 | 说明 |
| --- | --- |
| 伤害分位入库 | 每对缓存有胜时伤害、败时伤害的 25/50/75 分位 |
| 搜索可复跑 | 网格表含保血相关、重叠回合的综合相关，以及加权后的选点目标 |
| 已经替换 | **仅在 ADR-0018 的「有效」成立之后**：`strength.jsonl` 与展示分位的复盘改用新 \(s\)。搜索阶段只写旁路，不覆盖现行分位 |

**非目标：** 改参照池、面板、放宽阶梯；把本场真实胜负写进 \(s\)；用游戏伤害上限 5/10/15 当归一化或截断；六个分位各自自由加权；用最后 3 场的目标去调 T5 及以前的平权（该段已锁死）。

## 2. 依据

| 来源 | 约束 |
| --- | --- |
| ADR-0016 / 0017 / 0018 | 公式与选点见 0016、0017。何时覆盖 P3 的分位产物见 0018 |
| 现缓存 `pairs` | 有胜/平/负次数和 `avDamage`。`avDamage` **拆不出**胜时伤害和败时受伤的分位 |
| ReplaySim | 未读 `damageResults` |
| P3-T4 | 2026-10-05 有名次的局只有 7 局。搜索前重数一遍 |

**Q-020（2026-10-11）：** `damageResults` 是每次模拟一条有符号伤害（正=造成，负=受到，0 与平局一致），但在 `DamageCap` 为 5/10/15 时从不超过该上限。伤害系数取 0，不补伤害列。平权曲线仍按 §3.1 搜索；选点退回最后 3 场的 \(Q\) 均值对 \(-\mathrm{placement}\)（ADR-0017）。

动机例子在伤害项为 0 时：平权 \(w>4/7\approx0.57\) 则 \(0.2/0.8/0\) 高于 \(0.6/0.1/0.3\)。地板 0.6 满足这一点，所以任何回合都不会再倒向后者（只看胜平负时）。

## 3. 方案

### 3.1 得分

胜权固定为 1，负的胜平负项权为 0。平权：

- \(t\le 5\)：\(w=1\)
- \(t>5\)：线性降到 **0.6**，降完的回合 \(t_1\) 是搜索参数，之后保持 0.6

伤害第一阶段只用中位数。25/75 分位入库，不进网格。

\[
s = P_w + w(t)\,P_t + \lambda(t)\big(\alpha\,z_{\text{deal}} - \beta\,z_{\text{take}}\big)
\]

- \(z_{\text{deal}}\) / \(z_{\text{take}}\)：该对模拟里胜时伤害、败时受伤的中位数，各除以同回合全部配对的相应中位数的中位数。没有胜或没有败时，对应项为 0
- 尺度来自模拟分布，不用 5/10/15
- \(\lambda(t)=0\) 当 \(t\le t_d\)；之后线性升到 1
- \(\alpha,\beta\ge 0\)

循环赛、留一局、参照权重不变。T5 及以前 \(\lambda=0\) 且 \(w=1\)，网格上每个点的前期 \(s\) 都一样。

### 3.2 两个目标，重叠回合各取一半

**平均掉血** \(B(x)\)：\(x\) 与同回合参照对手逐一模拟，己方英雄伤害里只累加输掉的那些（胜和平为 0），对对手取平均。\(u(x)\) 是 \(B\) 在**同一回合**里的保血分位：掉血越低，\(u\) 越接近 1。不同回合的原始伤害不放在一起排名。

场面分成两类：

| 场面 | 标签 | 相关 |
| --- | --- | --- |
| 最后 3 场以外，以及没有名次的局的全部己方场面 | \(u\) | \(\rho_{\text{out}}=\rho(Q,u)\) |
| 有名次的局的最后 3 场（含淘汰战；第 1 名为终局最后 3 场） | \(y=\frac{1}{2}v+\frac{1}{2}u\) | \(\rho_{\text{over}}=\rho(Q,y)\) |

\(v\) 是名次分位（第 1 名最高），同一局的 3 场共用。\(Q\) 用分位，避免原始 \(S\) 随回合变尺度。

选点目标：

\[
J = \frac{n_{\text{out}}\,\rho_{\text{out}} + n_{\text{over}}\,\rho_{\text{over}}}{n_{\text{out}}+n_{\text{over}}}
\]

\(n\) 是各自的场面数。每个场面投一票，所以场面多的保血段权重大。名次不会因此消失：它已经占了最后 3 场那个标签的一半。若两段相关直接五五开，少量结局场面会和其余所有场面一样重。

\(B\) 和 \(Q\) 来自同一批模拟。受伤权重 \(\beta\) 越大，\(Q\) 越像保血分位，\(\rho_{\text{out}}\) 会偏向大 \(\beta\)。重叠回合里的名次一半用来拉住这件事。T5 及以前各网格点的 \(Q\) 相同，这些场面的保血相关不改变谁最高。

### 3.3 搜索与替换

| 参数 | 候选 |
| --- | --- |
| \(w_\infty\) | 固定 0.6，不搜 |
| \(t_1\) | 9、12、15 |
| \(t_d\) | 5、8、11 |
| \(L\) | 3、6 |
| \(\alpha,\beta\) | 0、0.05、0.10 |

基线行仍算现公式（平权 0.5、无伤害），\(J\) 的定义与新公式相同，方便看替换掉了什么。基线不写回引擎。

每个点报 \(\rho_{\text{out}}\)、\(\rho_{\text{over}}\)、\(J\)、两段场面数，以及局级 bootstrap 的 \(J\) 区间（重抽的是有名次的局；没有名次的局整局跟进或整局留出）。

采用规则：取 \(J\) 最高的点记为候选。**不在此时覆盖** `strength.jsonl`。是否重做依赖战力分的 P3 产物，按 ADR-0018：候选同时满足「\(J\) 高于旧公式基线」「保血或退回名次的相关方向正确且不低于基线」「有名次的局不少于 12」才算有效，然后才替换分位文件并重跑退出第 1、3 条和复盘页上的分位。不足 12 局或未高于基线时，搜索算完成，P3 那些产物保持不动。

Q-020 若判定伤害被上限截断，则没有可用的 \(B\)，选点退回「最后 3 场的 \(Q\) 均值对 \(-\text{placement}\)」（ADR-0017）。平权曲线仍替换旧公式。

### 3.4 数据

1. Q-020：少量对战看 `damageResults` 是否越过 `DamageCap`。被截断则 \(\alpha=\beta=0\)，不补伤害列。
2. 否则重放写入六个分位，`pairs` 加列，不覆盖胜平负次数。
3. 当前池补一次这些分位。

新 \(s\) 不再用 \(s(1-s)/n\)。替换上线时区间先标为未按新公式估计，随后单做方差。

## 4. 考虑过的替代方案

| 方案 | 不选的原因 |
| --- | --- |
| 新旧公式并列，\(n<12\) 不替换 | 所有者要求直接替换 |
| 平权地板搜到 0.5 | 动机例子在后期会倒向高胜率；地板已定为 0.6 |
| 重叠回合只把名次当主目标、保血作附注 | 所有者要求两目标综合；各一半写进 \(y\) |
| 两段 \(\rho\) 直接五五开 | 最后 3 场场面少，会和其余所有场面一样重 |
| 用 `avDamage` 或六个分位自由系数 | 前者胜负伤害抵消；后者参数多于名次局 |

## 5. 验收方式

- 合成测试：任意回合 \(0.2/0.8/0\) 的胜平负部分高于 \(0.6/0.1/0.3\)；\(t\le 5\) 时 \(w=1\)；\(t\ge t_1\) 时 \(w=0.6\)；无胜则伤害正项为 0
- Q-020 写入 `docs/facts/`
- 网格表含基线行、\(\rho_{\text{out}}\)、\(\rho_{\text{over}}\)、\(J\) 和两段场面数；采用点写明有名次的局数
- 替换后的 `strength.jsonl` 与旧文件在同一场面的分位允许不同；用固定小缓存断言新 \(s\) 与手算一致

## 6. 风险与回退

| 风险 | 处理 |
| --- | --- |
| 伤害被上限截断 | \(\alpha=\beta=0\)，仍替换平权曲线 |
| 有名次的局很少，最高点是噪声 | 仍然替换，并写明待 \(n\ge 12\) 重搜 |
| \(B\) 与 \(Q\) 同源，大 \(\beta\) 天然抬高保血相关 | 重叠回合的名次占一半；报告里同时给出 \(\rho_{\text{over}}\) 对名次的单独相关，便于看出掉血是否盖过名次 |
| 补模拟耗时 | 只补分位列；可按回合分批 |

回退：把采用点改回平权 0.5、伤害系数 0，即可复现旧 \(S\)。不删新列。

## 8. 已确认

1. 最后 3 场包含淘汰那一战；第 1 名用终局最后 3 场。
2. 平权地板固定 0.6，不搜。
3. 名次局不足 12，或候选未高于基线：搜索可以完成，但不算有效，不重做依赖战力分的 P3 产物（ADR-0018）。
4. 最后 3 场以外只优化保血（同阶段模拟的平均掉血低）。重叠场面的标签是名次分位和保血分位各一半，两段相关按场面数加权。
