# 方案：对战得分的第二轮搜索

- **状态：** approved（所有者 2026-10-11 接受 [ADR-0019](../decisions/0019-score-search-shape-and-midgame.md)）
- **任务：** 主线外。取代 `R-score-policy-search.md` 的选点与网格；得分的锁（第 5 回合及以前平权为 1、地板 0.6、胜权 1）仍沿用 ADR-0016
- **作者 / 日期：** agent / 2026-10-11
- **相关：** ADR-0016、ADR-0017、ADR-0018、ADR-0019；`facts/damage-results-cap-q020.md`；`facts/score-policy-search-raw-place-20261011.md`

## 1. 目标与非目标

**目标：** 在平权单调下降的少数形状里，用第 6–14 回合的保血分位选出一条曲线，并用最后 3 场对名次卡住它。确认半对局上也要有明显提升，才允许替换现行战力。

| 做完 | 说明 |
| --- | --- |
| 形状搜索可复跑 | 旁路表含每个形状在拟合半、确认半上的 \(\rho_{\mathrm{mid}}\)、\(\rho_{\mathrm{end}}\) |
| 伤害摘要 | 仅当第一阶段采用了曲线，才为第二阶段补「败局受到伤害」的摘要 |
| 替换分位 | 只有确认半过门之后。不过门则搜索完成，`strength.jsonl` 不动 |

**非目标：** 按回合自由设平权；搜地板或放开第 5 回合及以前；把造成伤害再加一个自由系数；用 5/10/15 当归一化；用上一轮 \(t_1=15\) 相对基线高出的 0.006 当作已经采用；改参照池、面板、\(G_{\min}\)、L1/L2。

## 2. 依据

| 来源 | 约束 |
| --- | --- |
| ADR-0016 | 第 5 回合及以前 \(w=1\)，之后降到 0.6 并不再下降。动机例子要求 \(w\ge 0.6\) |
| Q-020 | 上限为正时 `damageResults` 不越过上限。贴在上限上的样本没有「超过上限多少」的信息 |
| 2026-10-11 第一轮搜索 | 只看最后 3 场对名次时，\(t_1\in\{9,12,15\}\) 的 Spearman 为 0.383 / 0.382 / 0.387，基线 0.381。最后 3 场大多已到地板，三条曲线分不开 |
| 名次 | 用局末快照己方英雄的 `PLAYER_LEADERBOARD_PLACE`。与团子名次 11 局中 8 局相同 |
| ADR-0018 | 未过本方案的确认门之前，不覆盖 `strength.jsonl`，不改 T4 结论，不重做复盘页上的分位 |

## 3. 方案

### 3.1 锁住的得分

\[
s = P_w + w(t)\,P_t
\]

第一阶段没有伤害项。\(w(t)\) 满足：\(t\le 5\) 时为 1；\(t\) 增加时不上升；最终为 0.6，且不低于 0.6。

### 3.2 形状（一共 10 条）

节点只取这些回合。两节点之间按回合号线性插值。

| 族 | 参数 | 条数 | \(w\) |
| --- | --- | --- | --- |
| 一段线性 | \(t_1\in\{9,12,15\}\) | 3 | 回合 5 为 1，到 \(t_1\) 线性降到 0.6，之后保持 |
| 一次跳变 | \(t_1\in\{9,12,15\}\) | 3 | \(t<t_1\) 为 1，\(t\ge t_1\) 为 0.6 |
| 两段线性 | \((t_a,t_b)\in\{(9,15),(12,18)\}\)，\(w(t_a)\in\{0.8,0.9\}\) | 4 | 回合 5 为 1，到 \(t_a\) 线性降到 \(w(t_a)\)，再到 \(t_b\) 线性降到 0.6，之后保持 |

\(w(t_a)=0.8\) 是前段降得多，\(0.9\) 是前段降得少。基线仍是常数平权 0.5、无伤害，用同一套标签，不写回引擎。

### 3.3 两个标签

**中段保血。** 只看回合 6–14 的己方场面。\(B\) 是该场面对同回合参照对手的平均受到伤害：胜和平记 0；败局里没贴上限的用样本伤害，贴在上限上的记成上限。同一回合上限相同，所以贴顶只是把特别大的伤害捏在一起，没贴顶的仍然能分先后。\(u\) 是 \(B\) 在该回合内的保血分位，掉血越低 \(u\) 越高。

\[
\rho_{\mathrm{mid}}=\rho(Q,u)
\]

**末段名次。** 有局末名次的局，取最后 3 场分位的均值，对 \(-\mathrm{placement}\)。这是约束，不是用来把 10 条曲线互相拉开的主目标。

\[
\rho_{\mathrm{end}}=\rho(\bar Q_{\text{最后 3 场}},\,-\mathrm{placement})
\]

名次只取 `game_end` 快照。没有这场快照的局不进入 \(\rho_{\mathrm{end}}\)，它的第 6–14 回合场面仍可进入 \(\rho_{\mathrm{mid}}\)。

### 3.4 对半与采用

按 `gameId` 的时间顺序把局对半。一局的全部分面只进一半。前一半拟合，后一半确认。确认半不参与挑选。

拟合半里，先丢掉 \(\rho_{\mathrm{end}}\) 低于基线的曲线，再取 \(\rho_{\mathrm{mid}}\) 最高的一条作为候选。

采用须同时满足：

1. 确认半上 \(\rho_{\mathrm{mid}}\) 高于基线，且差值的点估计 \(\ge 0.05\)。
2. 确认半上 \(\rho_{\mathrm{end}}\) 不低于基线。

0.05 是为了拦住 0.006 这种落在区间噪声里的差距，不是显著性检验。表里仍报告局级 bootstrap 区间。没有曲线过门：搜索完成，不替换分位文件。

### 3.5 第二阶段（仅第一阶段采用之后）

在已采用的 \(w(t)\) 上只加受到伤害，且只在 \(t>5\)：

\[
s = P_w + w(t)\,P_t - \beta\,z_{\mathrm{take}}
\]

\(\beta\in\{0,0.05,0.10\}\)。\(z_{\mathrm{take}}\)：该对败局里**没贴上限**的伤害中位数，除以同回合全部这类中位数的中位数。败局里有一半及以上贴在上限上，或没有没贴顶的败局，则 \(z_{\mathrm{take}}=1\)（只表示「已到顶」）。不搜造成伤害，不搜伤害从哪一回合开始、升满要几回合。

用同一套 \(\rho_{\mathrm{mid}}\)、同一套确认门在 \(\beta\) 里挑。\(\beta=0\) 就是第一阶段的曲线。确认半不过门则伤害系数保持 0。

现有 `pairs` 没有这条摘要。第二阶段开始前，用 ReplaySim 在原胜平负之外写入：败局数、贴上限的败局数、未贴顶败局的伤害中位数。不覆盖胜、平、负次数。先做耗时估计，按现有回填的 2 小时上限；超过则停，不擅自开跑。

### 3.6 替换

确认门通过之后才按 ADR-0018 更换依赖战力分的产物：备份并替换 `strength.jsonl`，新方差下重测退出第 1 条，用新分位另写退出第 3 条的事实，重生成带分位的复盘页。上一轮字面有效的 \(t_1=15\) 不视为本方案的采用点。

## 4. 考虑过的替代方案

| 方案 | 不选的原因 |
| --- | --- |
| 继续只搜 \(t_1\in\{9,12,15\}\) 对最后 3 场名次 | 三条曲线在最后 3 场几乎都已是 0.6，第一轮已经分不开 |
| 每个回合一个平权，或两段以上再各换公式 | 参数多于确认半能撑住的局数 |
| 把 162 点的伤害网格铺回最后 3 场 | 主目标看不见这些参数，容易在同一批局里过拟合 |
| 用真实下一回合掉血代替模拟的 \(B\) | 一场只有一个真实对手，对不上「同回合所有参照场面」 |
| 确认门改成区间下界必须大于 0 | 确认半大约二十几局，Spearman 的区间宽到 0.05 的提升也过不了，搜索会失去分辨能力 |

## 5. 验收方式

- 合成测试：10 条曲线在任意回合都有 \(w\in[0.6,1]\)，\(t\le 5\) 时 \(w=1\)，并且不随回合上升；\(0.2/0.8/0\) 的胜平负部分高于 \(0.6/0.1/0.3\)
- 旁路表含基线、拟合半与确认半的 \(\rho_{\mathrm{mid}}\)、\(\rho_{\mathrm{end}}\)、场面数、有名次局数
- 采用点写明形状参数，以及确认半差值是否 \(\ge 0.05\)
- 未过门时 `strength.jsonl` 的修改时间不变

## 6. 风险与回退

| 风险 | 处理 |
| --- | --- |
| 贴顶太多，中段保血分不开 | 报告贴顶比例。分不开则不要靠放大 \(\beta\) 硬分 |
| 确认半没有曲线过门 | 这是允许的结果。不替换 |
| 伤害摘要要重放全池 | 先估时，超过 2 小时就停。第一阶段本身只用胜平负，不靠这次重放 |
| 局末名次与团子不一致 | 继续用局末标签，表里单独列出不一致的局 |

回退：不采用任何曲线，引擎保持 \(P_w+0.5P_t\)。

## 7. 任务拆分

1. 10 条曲线与「不低于 0.6、前期为 1、单调」的测试
2. 中段保血与末段名次的标签、对半、确认门（仍用现有胜平负；\(B\) 用本方案的受到伤害定义，摘要未就绪时第一阶段先只跑形状——见下）
3. 拟合半选曲线，确认半判定。旁路写入 `data/strength/1.85.0.0/score-policy-v2/`
4. 仅当第 3 步采用曲线：补伤害摘要，搜 \(\beta\)
5. 仅当确认门通过：按 ADR-0018 替换分位并重做退出第 1、3 条和复盘页

第 2 步的 \(B\) 需要败局伤害。缓存里没有。因此第 2 步之前先做**只服务标签**的摘要回填（与第 4 步同一批列），估时通过才跑。摘要未写完时不开始选点。

## 8. 待确认

1. 10 条形状的节点与 \(w(t_a)\in\{0.8,0.9\}\) 如上，不再加节点。
2. 确认半 \(\Delta\rho_{\mathrm{mid}}\ge 0.05\) 且 \(\rho_{\mathrm{end}}\) 不低于基线，才采用。
3. 名次继续用局末 `PLAYER_LEADERBOARD_PLACE`。
4. 第二阶段只搜一个 \(\beta\)，造成伤害不进网格。
