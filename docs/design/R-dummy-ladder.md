# 方案：木桩梯队绝对值

- **状态：** implemented（旁路；未并入主线战力）
- **任务：** 主线外。不替换 ADR-0003 的历史分位。
- **作者 / 日期：** agent / 2026-10-18
- **相关：** ADR-0003、`facts/strength-cross-p3t0.md` §6（历史固定基准集弱于全池）、Q-021

## 1. 目标与非目标

**目标：** 对任意待评估场面，只和一组事先定好的静态对手打，得到一个带单位的绝对值，并给出一套可重复的好坏标准。绝对值的单位是：场面与「7 个完全相同的无词条随从」打成五五开时，这 7 个随从的攻/血。

**非目标：** 不改 `strength.jsonl`，不进 P4，不把英雄技能、任务、饰品从待评估场面里剥掉。对手侧不用真实玩家的任何计数器。

## 2. 依据

- 模拟器能用卡牌工厂造随从再改写攻血。`CFM_315t`（无战吼、无亡语的 1/1 野兽衍生物）在 BB 1.88.6 上，7×10/10 对 7×1/1 胜率 100%，7×3/3 对 7×3/3 平局 100%（本 spike 自测）。
- 当前模拟池 `1.85.0.0` 的己方非空场面约 1321 个（115 局）。攻击总和中位数大约是：回合 3 为 7，回合 6 为 36，回合 8 为 108，回合 10 为 452，回合 12 为 1413。所以同一套木桩要覆盖 1 到至少两千。
- P3-T0 的「固定基准集」抽的是真实历史场面，和这里的人造木桩不是一回事。那次结论不直接否定木桩。

假设：无词条野兽不会因为种族吃到待评估场面不该给的光环。对手是新建的空玩家，不继承原对手的甲虫、宝石等计数器。若自测以外的曲线大面积不单调，先怀疑这个假设。

## 3. 方案

### 3.1 木桩

每个梯级是 7 个攻 = 血 = L、无嘲讽、无圣盾、无风怒、无剧毒的 `CFM_315t`。待评估侧保持原 Input（含英雄技能、饰品、任务、畸变、回合）。对手英雄血量固定 40，等级 1，没有技能、饰品、手牌。

探测梯队（公比 2，先求覆盖，再决定能不能抽稀）：

`L = 1, 2, 4, 8, 16, 32, 64, 128, 256, 512, 1024, 2048`

每次模拟 500 次，与战力引擎默认次数相同。DLL 用池内已安装的最新版 `1.88.6.0`。

### 3.2 绝对值

对梯级 L 的得分沿用 ADR-0003 的组合，权重为 1：

\[
s(L) = P(\mathrm{win}) + 0.5\,P(\mathrm{tie})
\]

主绝对值 \(X_{50}\)：在 \(\log_2 L\) 上对 \(s(L)=0.5\) 做线性插值，再变回攻血。插值取第一处从 ≥0.5 落到 <0.5 的相邻梯级。最低梯级已经 <0.5 记 `below`，最高梯级仍 ≥0.5 记 `above`，这两种没有内点绝对值。

对照公式：在 \(\log_2 L\) 上用最小二乘拟合 logistic，取预测得分 0.5 的点。两条公式的 Spearman 若低于 0.95，说明曲线不像一条单调的 S 形，单一绝对值概括不了。

### 3.3 好坏（预先写死，看完曲线再填数）

一套「梯队 + \(X_{50}\)」要同时看这些，不能只看和历史分位像不像：

| 检查 | 通过样子 | 为什么 |
| --- | --- | --- |
| 覆盖 | 回合 4–12 的场面里，内点（不是 below/above）占多数 | 梯队太窄时绝对值被截断，没有分辨率 |
| 单调 | 单个场面的 \(s(L)\) 随 L 上升不出现超过 0.05 的反跳 | 500 次的抽样标准差在 0.5 附近约 0.02；超过 0.05 更像木桩或接线有问题 |
| 随回合升高 | 各回合内点 \(X_{50}\) 的中位数从回合 4 到 12 整体上升 | 这是绝对值相对「同回合分位」多出来的性质；分位在每个回合里中位数天然约 0.5 |
| 公式一致 | 内点上插值与 logistic 的 Spearman ≥ 0.95 | 否则换公式而不是先换梯队 |
| 同回合对齐历史分位 | 有分位的回合里，\(\log_2 X_{50}\) 与分位的 Spearman 中位数 ≥ 0.6 | 对齐高说明木桩排序和全池循环赛排序接近，绝对值可以作为便宜的平行刻度。对齐低不一定失败，要再看下一行 |
| 同回合对实际胜负 | 在去掉平局的战斗上，\(\log_2 X_{50}\) 预测胜/负的 AUC 不比现有分位差一截（差距 ≤ 0.05） | 实际对手强弱会同时干扰两者；只比较两者的相对高低 |

不把「全局 \(X_{50}\) 对最终名次」当作主标准。活得更久的场面木桩绝对值天然更大，和名次缠在一起。

探测样本：每个回合（3–14）按 `gameId` 排序后取首、中、尾各 1 个非空己方场面，共约 36 个。先看覆盖和单调，再决定第二轮是加长梯队、抽稀，还是扩大样本。

## 4. 考虑过的替代方案

| 方案 | 不选的原因 |
| --- | --- |
| 木桩数量随己方随从数变化 | 绝对值的单位会跟着场面宽度变，跨场面不可比。数量固定为 7 |
| 攻高血低的长条木桩 | 对圣盾、剧毒的定价会变。第一轮只做方阵，留作后续 |
| 用得分对 L 的积分当绝对值 | 和 50% 点在阶跃曲线上重合，在缓坡上会偏向「赢过的梯级面积」，不如「打平的那一档」好解释 |
| 每个回合一套不同梯队 | 分辨率更高，但失去跨回合的同一单位 |

## 6. 风险与回退

- 野兽衍生物可能吃到只对野兽结算的效果。若曲线反跳集中在少数卡，换无种族白卡再测。
- 畸变若给双方加同样的身体，会压缩绝对值的差距。第一轮不剥畸变。
- 几何梯队在跨越处最多偏半档（例如 64 与 128 之间）。若第二轮发现胜负几乎是阶跃，可以把档数减半，误差仍约半档。
- 本方案失败就停在旁路，主线继续用历史分位。

## 8. 实测（2026-10-18）

自测通过。探测 36 场面见 `facts/dummy-ladder-20261018.md`：公比 2 的格子上曲线几乎是阶跃，所以加了括号内公比 \(2^{1/8}\) 的加密；回合 14 会打穿 2048，粗档上沿放到 8192。加密后的 \(X_{50}\) 通过第 3.3 节全部门。同回合与历史分位 Spearman 约 0.93–0.96；预测实际胜/负的 AUC 比分位低 0.044。

因此这套刻度可以当作带单位的平行读数，同回合名次和全池分位几乎一致。它没有取代历史对战：实际胜负上仍略弱，而且主线分位文件没有改。
