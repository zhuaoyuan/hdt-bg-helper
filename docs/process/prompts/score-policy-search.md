# 提示词：落地随回合变化的对战得分

> 用途：新会话里先做成新算分引擎并搜索参数。原始对战数据复用。依赖战力分的 P3 产物，等搜索完成且判定有效之后再重做。  
> 公式与选点：[`R-score-policy-search.md`](../../design/R-score-policy-search.md) §3.1–§3.2、[ADR-0016](../../decisions/0016-turn-dependent-matchup-score.md)、[ADR-0017](../../decisions/0017-score-search-blood-and-placement.md)。  
> 与现行 P3 的冲突和时机：[ADR-0018](../../decisions/0018-reuse-raw-redo-score-dependents.md)。方案 §3.3 里「立即覆盖分位文件」的句子以 ADR-0018 为准。

## 所有者可粘贴的短指令

```text
落地新对战得分，严格按 docs/process/prompts/score-policy-search.md。
公式和选点以 docs/design/R-score-policy-search.md §3.1–§3.2、ADR-0016、ADR-0017 为准，不要改。
原始模拟与标准层复用。依赖战力分的 P3 产物按 ADR-0018：搜索完成且有效之后才重做；未有效则不要覆盖现行 strength.jsonl。
先做 Q-020。每步一个 commit，不要 push。
```

## 开始前（必读顺序）

1. `AGENTS.md` → `docs/status.md` → `docs/roadmap.md` 的 P3 目标与三条退出标准。
2. 方案 §3、§8；ADR-0016、0017、0018；Q-020。
3. 现引擎：`tools/strength/`、`tools/ReplaySim/Program.cs`。现行分位在 `data/strength/1.85.0.0/strength.jsonl`。缓存有胜平负次数和 `avDamage`，没有条件伤害分位。
4. 从 `main` 建分支 `feat/score-policy`。

## 本任务范围

### A. Q-020（先于改缓存）

少量真实配对（约 3～5 对，含一个明显能超过当回合伤害上限的胜面），比较 `damageResults` 与 `DamageCap`。

- 写入 `docs/facts/`：是否越过上限、有符号约定、胜/平时是否为 0。更新 Q-020。
- **从不超过上限：** 不补伤害列，\(\alpha=\beta=0\)，选点退回「最后 3 场 \(Q\) 均值对 \(-\mathrm{placement}\)」。继续做平权曲线搜索，不要补跑全池。

### B. 伤害分位（仅 Q-020 通过时）

`ReplaySim` 按胜/败写下 25/50/75 分位和样本数。胜和平的掉血记 0。`pairs` 加列，不改已有胜平负。对池 `1.85.0.0` 补列，可按回合分批。不改参照池、面板、L1/L2。

### C. 搜索（完成，但先不要动 P3 产物）

按方案 §3.1–§3.2 实现。平权地板固定 0.6，T5 及以前为 1，\(t_1\in\{9,12,15\}\)，伤害网格见方案。合成测试锁住：任意回合 \(0.2/0.8/0\) 的胜平负部分高于 \(0.6/0.1/0.3\)。

网格写到旁路目录（例如 `data/strength/1.85.0.0/score-policy/`）：每个点的参数、\(\rho_{\mathrm{out}}\)、\(\rho_{\mathrm{over}}\)、\(J\)、场面数、有名次局数、bootstrap 区间，以及重叠场面的 \(Q\) 对名次的单独相关。基线是平权 0.5、无伤害，同一套 \(J\)。

**不要**覆盖 `strength.jsonl`，**不要**改 `docs/facts/strength-validity-p3t4.md` 的结论，**不要**重生成复盘页。

### D. 判定有效，通过才重做 P3

有效须**同时**满足（ADR-0018）：

1. 采用点的 \(J\) 高于旧公式基线。
2. 有 \(B\) 时 \(\rho_{\mathrm{out}}>0\)；没有 \(B\) 时，最后 3 场分位对 \(-\mathrm{placement}\) 的相关为正，且不低于基线。
3. 有名次的局不少于 12。

缺一：在事实里写「搜索完成、无效」，停在这里。

三条都满足时，按上表重做依赖战力分的部分：备份并替换 `strength.jsonl`；新方差下重测退出第 1 条；用新分位重跑退出第 3 条并另写事实（不要涂改 2026-10-05 那份旧结论，注明已被哪次重跑取代）；重生成带分位的复盘页；更新路线图 P3 目标句。方案改为 `implemented`。

## 明确不做

- 未有效就覆盖现行分位、改 T4 结论或重做复盘。
- 推倒胜平负缓存重模拟；改参照池、面板、\(G_{\min}\)、L1/L2、迭代次数。
- 把真实胜负或真实掉血写进 \(s\) 或 \(B\)；用 5/10/15 当归一化。
- 搜索平权地板，或放开 T5 以前平权必须为 1。
- 用 \(J\) 代替退出标准第 3 条。
- `git push`。
