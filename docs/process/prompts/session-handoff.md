# 提示词：会话收尾交接

会话结束前，确保下一个没有任何记忆的 agent 能直接接上。

## 步骤

1. **更新 `docs/status.md`**
   - "最后更新"日期；
   - 把本次完成的内容写进"最近完成"（只保留最近几项，更早的在 worklog 里能找到）；
   - "进行中"写清楚做到了哪一步、代码在哪个分支、从哪继续；
   - "下一步"按优先级排好，每项带任务编号；
   - "阻塞 / 需要所有者决定"写清楚需要确认什么。
2. **更新 `docs/roadmap.md`**：完成的任务打勾（满足 `process/sdlc.md` 中的完成定义才打勾）。
3. **写 worklog**：`docs/worklog/YYYY-MM-DD-short-title.md`，同一天多次会话可以追加到同一个文件。内容包括：
   - 目标：这次要做什么；
   - 做了什么：关键步骤和结果；
   - 发现：意外情况、踩的坑、否定掉的思路；
   - 留下的东西：新增或修改的文件、分支、未完成的部分。
4. **检查知识是否落地**：对话里得出的结论，都已经写进 `facts/`、`decisions/`、`open-questions.md` 或方案里了吗？
5. **给所有者一段简短总结**：做了什么、结果如何、需要他做什么决定。
