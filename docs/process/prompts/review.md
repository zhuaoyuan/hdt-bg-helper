# 提示词：提交前自审

提交之前，逐条检查你的改动。发现问题先修，修不了的写到 worklog 和 `status.md`。

## 正确性

- [ ] 改动满足方案中这一步的验收方式，并且实际运行过
- [ ] 边界情况：双人模式、断线重连、对手是"鬼魂"、场上 0 个或 7 个随从、未知卡牌
- [ ] 采集失败时不会抛异常到 HDT，不会阻塞 HDT 的事件线程

## 数据

- [ ] 未知信息记为未知，没有被静默填成默认值
- [ ] schema 有变化时，版本号已递增，旧数据仍能读取或有迁移说明
- [ ] 没有在仓库中提交个人对局数据或其他玩家的 BattleTag

## 一致性

- [ ] 与已接受的 ADR 一致；如果不一致，已提新 ADR
- [ ] 引用的 HDT 源码位置与当前基线一致
- [ ] 代码风格与周围代码一致；注释只写代码本身表达不了的约束

## 文档

- [ ] 新事实、新决定、新问题已写入对应文档
- [ ] `status.md` 与 worklog 已更新

## 提交

- [ ] 只包含与本任务相关的文件
- [ ] commit 消息使用约定式前缀，说明了为什么改
