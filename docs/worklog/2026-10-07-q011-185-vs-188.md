# 2026-10-07 Q-011：1.85 场面用 BB 1.88.6 重算

## 目标

用 BB 1.88.6 DLL 重放采集于 1.85.0 的 `_input`，看五率是否相对 1.85 同版重放 / 记录 Output 有显著差异。

## 做了什么

1. `bb-dirs.json` 登记 `1.88.6.0` → `C:\Program Files\HDT`；去掉已过期的 `1.85.0.0:tuanzi`（该目录现为 1.88.6）。
2. `roundtrip.py`：`--alt-version`、`--roots`、q011 同时报 native-vs-alt 与 recorded-vs-alt。
3. 跑：`--mode q011 --versions 1.85.0.0 --alt-version 1.88.6.0 --limit 100`（约 6.2 min）。

## 发现

- **100/100** 场：1.85 vs 1.88.6 五率均在 3σ（含地板）内；相对记录 Output 亦 100/100。
- \|Δwin\| max≈0.01（对照：昔日 1.78→1.85 曾出现 Δwin≈0.23）。
- hydrate 失败 0：1.85 dump 可被 1.88.6 还原并模拟。
- **不**据此打开 L2 或混桶；默认仍按采集版本选 DLL。
