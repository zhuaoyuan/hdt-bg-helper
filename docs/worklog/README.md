# 工作日志

> 这份文档回答：每次会话做了什么、发现了什么。只追加，不改写历史。

- 文件名：`YYYY-MM-DD-short-title.md`；同一天多次会话可以追加到同一文件，用二级标题分段。
- 2026-09-26：[`2026-09-26-p1t3-field-analysis.md`](2026-09-26-p1t3-field-analysis.md)
- 内容格式见 [`../process/prompts/session-handoff.md`](../process/prompts/session-handoff.md)。
- 日志是过程记录。其中沉淀出的事实、决定、问题，必须另外写进对应文档，不能只留在日志里。
