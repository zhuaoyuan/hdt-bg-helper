# 摆位策略对战力 \(S\) 的增量（独立分析）

> 这份文档回答：在最新 BB 队列 T3–T7 上，简单身材加权摆位相对原摆位，能否系统性提高 ADR-0003 的 \(S\)。

```text
样本：BB 1.85.0.0；T3–T7；ready 双侧场面 308（约 30–31 局/回合）
工具：spikes/positioning/；ReplaySim batch；iterations=500
对手池：同回合全体场面；评估时剔除同一 boardId（不整局留出）
策略：atk_desc / hp_desc / atk1_hp1 / atk1_hp2 / atk2_hp1 / rev_orig / taunt_left_atk（高分靠左）
显著性：局聚类 bootstrap 95% CI；Wilcoxon；BH-FDR q=0.05（对非 orig 单元格）
墙钟：约 1006 s（~17 min 模拟；全进程 ~35 min 含拼装）
最后核实：2026-10-07
证据：data/positioning/1.85.0.0/summary.json、scores.jsonl；design/R-positioning-strength.md
```

## 1. 结论摘要

| 问题 | 结论 |
| --- | --- |
| 身材排序能否显著抬高 \(S\)？ | **不能。** 无任何 strategy×turn 的 \(\overline{\Delta S}\) 局聚类 CI **下界 > 0**（主结论标准） |
| 效应方向 | 默认策略池内均值 \(\overline{\Delta S}\) 多为**略负**（约 −0.001 ~ −0.019）；提升比例多在 0.1–0.55 |
| 原序反转 | **显著伤害**：各回合 \(\overline{\Delta S}\approx -0.021\sim-0.047\)，CI 全在 0 以下；Wilcoxon 经 FDR 均拒绝（相对 0） |
| 管线自洽 | `orig` 的 \(\Delta S\equiv 0\)；`nMissing=0`；模拟 ok 59956/59956 |

**含义：** 在本批个人数据与简单全局排序规则下，**没有证据**支持「按攻/血/加权重排」能抬高对同回合大厅池的战力 \(S\)；玩家原摆位明显好于「整板反转」，说明原摆位并非对 \(S\) 无信息的随机序，但也不能被这些身材规则系统性改进。

## 6. 局限

- 只测**全局身材排序**（及嘲讽靠左+攻序）；未测裂解邻接、亡语序、局部交换搜索。
- 对手池含 Opponent 侧场面；未做 leave-one-game。
- \(\Delta S\) 相对同回合大厅池，不是「对本场匹配」或名次标签。
- 效应量绝对值小（多 &lt; 0.02），接近/小于单场 MC 噪声尺度时解读宜谨慎；`rev_orig` 的负向效应明显更大且稳定。
