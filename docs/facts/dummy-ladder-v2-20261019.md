# 木桩梯队 v2：模型化估计 + 自适应采集（实测）

> 这份文档回答：把 v1 的两档线性插值换成「全部档位的 logistic 位置 + 区间」、把固定加密换成「粗档 + 自适应 4 + 2 点」之后，读数是否与 v1 一致、区间是否可用、成本降了多少、对实际战果的区分度有没有变化；以及**跨 BB 版本是否稳定**、**战果差距在按局聚类 bootstrap 下还剩多少**。

```text
样本：模拟池 1.85.0.0（成员 1.85.0.0、1.88.6.0）的己方非空场面；回合 6/8/10，共 329 个
模拟：BobsBuddy.dll 1.88.6.0（C:\Program Files\HDT），iterations=500
木桩：CFM_315t，攻=血=L；粗档公比 4（1..16384），自适应两轮
工具：spikes/dummy-ladder/{model_estimate,run_adaptive,compare_estimators,score_model_outcomes,cross_dll,bootstrap_outcomes}.py
最后核实：2026-10-19
证据：spikes/dummy-ladder/out-adaptive/{run.json,curves.json,outcomes.json,bootstrap.json}、out-wide/curves-model.json、cross-dll/compare.json（本地 gitignore，可按 design/R-dummy-ladder-v2.md 重跑）
```

## 1. 结论摘要

| 检查 | 结果 |
| --- | --- |
| 估计量自测 | **PASSED**：恢复 \(a\) 误差 **0.001**、\(b\) 相对误差 **2.3%**；CI 覆盖 **40/40**；密集合成曲线 model/interp 比值 **1.028**；饱和 0/1 档额外检查通过 |
| 只换估计量（同一批 v1 档位，329 板） | Spearman **0.9995**；中位 \(\lvert\log_2\) ratio\(\rvert\) **0.0203**（×1.014）；中位 CI 宽 **0.1134 log2**（×1.082）；>10% 的偏差 5 板，>25% 0 板 |
| 自适应全量（329 板） | **329/329 `interior`**；中位 **14 档/板**（v1 21）；中位 CI 宽 **0.129 log2**（×1.093）；墙钟 **126.8 s**（含索引）；与 v1 插值 Spearman **0.9992**、中位 ratio **×1.019**；成本比 **1.51×** |
| **跨 DLL（1.85.0.0 vs 1.88.6.0）** | 同一批 329 板、同一套 4601 个档位重放：**Spearman 0.9999**；中位 signed ratio **1.000**；中位 \(\lvert\)ratio\(\rvert\) **×1.002**（聚类 bootstrap 95% CI **×1.0015–×1.0024**）；>10% 仅 **1 板**（max ×1.18）；两版中位 CI 宽 0.1268 / 0.1289 log2 |
| **战果对比（按局聚类 bootstrap）** | 47 局 / 130 决胜：模型 AUC **0.7606** [0.6878, 0.8298]；主线分位 **0.8051** [0.7355, 0.8692]；**ΔAUC = −0.0445 [−0.0713, −0.0196]**；Δρ = **−0.0751 [−0.12, −0.034]**；v2 模型 vs v1 插值 ΔAUC **−0.0007 [−0.0163, 0.0131]** |
| **全回合敏感性（t1–t17）** | 1321 板：1112 interior / 198 below / 11 above；480 决胜（47 局）；模型 AUC **0.7664** [0.7211, 0.8110] vs 分位 **0.7951** [0.7567, 0.8326]；**ΔAUC = −0.0425 [−0.0663, −0.0197]**；t6/8/10 的选择不驱动结论；**t5 以前刻度不稳定**（t2/t3 CI 中位宽 30 log2） |
| 分回合中位 \(X_{50}\)（1.88.6） | t6 **7.78**（v1 7.68）、t8 **23.68**（24）、t10 **111.43**（112.41）；分回合 Spearman 0.9966 / 0.9929 / 0.9932 |

**一句话：** v2 复现了 v1 的刻度与战果区分度（AUC 差 0.0007），给出约 ±4.5% 的 95% 区间，每板模拟次数从约 21 降到 14；**同一批场面在 1.85.0.0 与 1.88.6.0 两个 DLL 下的 \(X_{50}\) 几乎不变（秩相关 0.9999，中位差 0.2%）**——这是“绝对值”主张的第一条直接证据。把回合扩到 t1–t17 后，**ΔAUC 仍然稳定在 −0.0425 [−0.0663, −0.0197]**，说明 t6/8/10 的选择没有驱动结论；但 **t5 以前 \(X_{50}\) 刻度不稳定**（大量 below、CI 退化），只适合 t5 以后。按局聚类 bootstrap 显示：**主线分位在实际战果上仍显著更好**，AUC 高约 0.04（95% CI 0.02–0.07），ρ 高约 0.07；v2 与 v1 插值之间则无法区分。

## 2. 怎么算的

- **估计量**：quasi-binomial logistic IRLS，\(\log_2 L\) 上的位置 \(a\)、尺度 \(b\)；每档 \(n\) 局、得分 \(s=P_w+0.5P_t\)；工作权重 \(n\,p(1-p)\)；主估计 \(X_{50}=2^a\)，区间由 Fisher 信息 \((J^\top WJ)^{-1}\) 给出。
- **采集**：粗档公比 4（8 档）→ 区间内 2 个几何点 + 2 个 logistic 目标点（\(p=0.25,0.75\)）→ 2 个目标点（\(p=0.4,0.6\)）。固定跑满，不按区间宽度提前停。
- **跨 DLL**：不用自适应重新选点，而是取 1.88.6 自适应跑出的同一套档位（每板 13–14 个，共 4601 个），分别用两个 `BobsBuddy.dll` 目录重放，再用同一 IRLS 估计比较。
- **战果 bootstrap**：按 `gameId` 有放回重采样 47 个局，每个 replicate 保留局内全部板（重复局也重复计数）；AUC 用决胜战斗（胜/负），ρ 用 win=1/tie=0.5/loss=0；回合中位数固定用全样本（329 板）估计。
- **对照**：v1 两档插值；PAVA 单调拟合（只作形状诊断）。

## 3. 跨 DLL 稳定性（2026-10-19 补）

| 指标 | 1.85.0.0 vs 1.88.6.0 |
| --- | --- |
| 配对板数 | **329**（桩位 4601 个，两版完全相同的档位与输入） |
| Spearman(\(X_{50}^{1.85}, X_{50}^{1.88.6}\)) | **0.9999** |
| 中位 signed \(\log_2\) ratio | 0.0000（×1.000） |
| 中位 \(\lvert\log_2\) ratio\(\rvert\) | **0.0027**（×1.002）；聚类 bootstrap 95% CI ×1.0015–×1.0024 |
| \(\lvert\)ratio\(\rvert>10\%\) | **1 板**（max ×1.18） |
| 中位 CI 宽 | 0.1268 / 0.1289 log2 |
| 分回合中位 \(X_{50}\) | t6 7.76 / 7.75；t8 23.62 / 23.77；t10 111.43 / 109.52 |
| 作业 | 两版各 4601 个，`ok` 4601/4601，**errors 0**；1.85 有 7706 条 hydration warnings，1.88 有 84 条 |

**解释：** 这是把“绝对值”从定义变成可用刻度的关键一步：同一批场面、同一套档位，只换 DLL，\(X_{50}\) 的排序几乎完全不变、中位系统偏移 0.2%。t10 的 1.85 中位比 1.88.6 低约 1.7%，但在单板 CI（×1.09）之内；单板最大差 18%，属于少数边界板。  
**注意：** 1.85 的 7706 条 hydration warnings 来自新版 Input 中该版本 BB API 不认识的字段/类型（如 trinket 等）；两版估计仍高度一致，说明这些缺失没有实质改变木桩读数的排序，但不能据此说“所有新机制都不影响”。1.78.1 未测。

## 4. 战果对比的按局聚类 bootstrap（2026-10-19 补）

样本：329 板中 135 板有 `turns.jsonl` 战果标签（标准层到 2026-10-10），其中 130 板决胜；按局聚类重采样 47 个局，B=5000。

| 指标 | 点估计 | 95% CI（按局聚类） |
| --- | ---: | --- |
| 模型 \(X_{50}\) AUC | **0.7606** | [0.6878, 0.8298] |
| v1 插值（自适应档位）AUC | 0.7562 | [0.6806, 0.8289] |
| v1 插值（v1 档位）AUC | 0.7613 | [0.6863, 0.8323] |
| 主线分位 AUC | **0.8051** | [0.7355, 0.8692] |
| **ΔAUC（模型 − 分位）** | **−0.0445** | **[−0.0713, −0.0196]** |
| 模型 \(\rho\) | 0.4432 | [0.3156, 0.5597] |
| 主线分位 \(\rho\) | 0.5183 | [0.3978, 0.6280] |
| **Δρ（模型 − 分位）** | **−0.0751** | **[−0.1200, −0.0340]** |
| ΔAUC（模型 − v1 插值） | −0.0007 | [−0.0163, 0.0131] |

**解释：**

1. **v2 与 v1 在战果上无法区分**（ΔAUC CI 含 0），换估计量/自适应采集没有改变区分度。
2. **主线分位在小样本上确实更好**：ΔAUC 的 95% CI 不含 0，P(ΔAUC<0)=4999/5000；ρ 同样显著。差距不大（约 0.044 AUC / 0.075 ρ），但这次不再是“无法判定”。
3. 这仍然是**描述性、在样本内、单补丁**的结论：47 个聚类、130 个决胜战斗；不能外推到别的版本或别的玩家池。

## 5. 全回合敏感性（2026-10-19 补）

为回答“t6/8/10 是不是结论的驱动因素”，用同一自适应流程重跑了 **回合 1–17 的全部 1321 个非空己方场面**：

| 项 | 结果 |
| --- | --- |
| 覆盖 | 1321 板：**1112 interior / 198 below / 11 above**；中位 14 档/板；墙钟 **304 s**；8.32M 次模拟 |
| 分回合中位 \(X_{50}\) | t1 1.03（6 interior）、t2 1.24（10）、t3 2.0、t4 3.03、t5 4.94、t6 7.78、t7 13.2、t8 23.71、t9 52.01、t10 110.35、t11 233.4、t12 473.5、t13 958.4、t14 1792.9、t15 3282.9（t16/17 n≤4） |
| 标签/决胜 | 542 板有标签；**480 决胜（47 局）**；模型可用的决胜 420，与分位重叠 419 |
| 模型 AUC | **0.7664** [0.7211, 0.8110] |
| 主线分位 AUC | **0.7951** [0.7567, 0.8326] |
| **ΔAUC（模型 − 分位）** | **−0.0425 [−0.0663, −0.0197]** |
| Δρ（模型 − 分位） | −0.0663 [−0.1057, −0.0287] |
| ΔAUC（模型 − v1 插值） | +0.0055（仅 t6/8/10 子集，CI [−0.0524, 0.0671]） |

**结论：**

- 全回合的 ΔAUC（−0.0425）与只用 t6/8/10 的 −0.0445 几乎相同，CI 略窄；**t6/8/10 的选择没有驱动“分位略优”的结论**。
- 分回合看，中盘（t3–t10）分位多数更好；晚回合（t11–t14）模型在少数局上反而更高（n=9–34），不能作结论。
- **早期回合的刻度不可用**：t1–t2 大多数板 `below`（\(X_{50}<1\)），t3 也只有 99/111 个 interior；t2/t3 的模型 CI 中位宽达 **30 log2**（退化拟合），t4 为 1.88，t5 才回到 0.27、t6 起约 0.1–0.15。\(X_{50}\) 只适合 **t5 以后**；全回合里模型决胜数（420）少于分位（479）主要就是这批 below 板。

## 6. 限制

- **样本（130 决胜的来历）**：329 个候选板来自模拟池的 **112 局**；`turns.jsonl`（标准层）只有 **933 行 / 79 局**（截至 2026-10-10）。两者只有 **47 局重叠**，逐回合能对上的板为 47 / 46 / 44（t6/8/10），其中有效标签 47 / 45 / 43，决胜 **43 / 45 / 42 = 130**；**65 局完全不在标准层**（10-11/10-17 之后的局，或未导入/partial 的局）。所以“130”不是扫了 130 场，而是“329 个候选板 ∩ 标准层标签 ∩ 决胜”。
- **全回合样本**：t1–t17 有 **542 板有标签、480 决胜**（仍 **47 局**）；模型可用 420（`below`/`above` 被排除），与分位重叠 419。增加回合能增加每局内的板数，但不能增加独立局数，聚类 CI 主要随局数收缩。
- **早期刻度不可用**：t5 以前大量 `below` 与退化 CI（t2/t3 中位 CI 宽 30 log2）；\(X_{50}\) 只适合 t5 以后，早期回合请用分位或 HDT 当场胜率。
- **有效独立单位**：聚类 bootstrap 的单位是 **47 局**，不是 130 或 480 个板；同局相邻回合高度相关，按板重采样会把区间算窄。
- **区间**：渐近近似、条件于已实现的两阶段设计；没有对自适应选点做整流程 bootstrap（这是估计量自身的 CI，不是战果对比的 CI）。
- **跨 DLL**：只测了 1.85.0.0 与 1.88.6.0；1.85 侧有大量 hydration warnings；1.78.1 未测；没有测“同一补丁内规则变化”。
- **单一木桩族**：仍是 7 个 `CFM_315t` 方阵；多木桩族按要求没做。
- **选点**：粗档默认公比 4，早期回合（1–4）的整数分辨率仍有限；`--coarse ratio2` 可回退 v1 口径。
