# P3-T1 战力引擎默认参数校准

> 这份文档回答：在 P3-T0 `out_both` 对集上跑完方案 §3.8 的 E1–E3（及可选 E5）后，各旋钮的实测取值与判据是否通过。

```text
样本：BB 1.85.0.0 队列 out_both（24 局，10552 对，iterations=4000 基线）；E3 turn±1 另跑 17942 对；E5 跨版本 10016 对
工具：spikes/strength-cross/tools/calibrate.py + ReplaySim --batch；分位按 ADR-0011 留一局循环赛（校准期同组成员仅 Player 侧，因 out_both 候选只有 Player）
最后核实：2026-10-05
证据：spikes/strength-cross/out_calibrate/{e1,e2,e3,e5}/report.json；design/P3-T1-strength-engine.md §3.8–3.9
```

## 1. 结论摘要（写入方案 §3.9 的默认值）

| 参数 | 校准后 | 依据 |
| --- | ---: | --- |
| `iterations` | **500** | E1：相对 4000 基线，\|ΔQ\| p95=0、Spearman(S)=0.9999；250 档 \|ΔQ\| p95≈4.5 未过 |
| `maxDurationMs` | **500** | 随迭代档；批跑时以迭代次数先到为准 |
| `panelGames` K | **30** | E2：K=20 的 \|ΔQ\| p95≈5.0 未过（阈值≤3）；K=30 在本批 24 局下等同全面板 |
| \(G_\text{min}\) | **6** | E3：L0 降采样中位 \|ΔQ\|≤10 的最小局数（G=4 中位≈11.4） |
| \(w_\text{relax}\) / L1 | **0.25 / 启用** | E3：G=6 时 w=0.25 中位误差最低（≈8.4），略优于纯 L0（≈9.1） |
| L2 跨版本 | **关闭** | E5：\|ΔQ\| p95≈13.6 >5 |
| bootstrap B | 1000（引擎默认；本校准 E1 宽度对照用 B=200） | — |
| 参照含对手场面 | 是（可关） | 沿用 P3-T0 |

E4（反对称省半）已在方案阶段否决，本校准未重开。

## 2. 方法要点

- **复用** P3-T0 `out_both` 的 `cross_results.jobs.jsonl` / 4000 次结果；未为校准重刷整池（当前可收集的 1.85 `ready`≤12 约 25–27 局，相对基线 +1–3 局，不改变档位判别）。
- **分位**：候选与同组成员对着同一对手面板算 \(S\)，再取加权经验 CDF（ADR-0011）。校准脚本在 out_both 约束下，**同组成员仅含有得分行的 Player 场面**；对手场面仍可进对手集。
- **聚类 bootstrap**：按局有放回重采样 + 蒙特卡洛噪声；E1 宽度对照在 120 个候选、B=200 上估计（节省 CPU）。中位宽度本批约 **36** 百分位点，且各迭代档几乎相同——分位离散（同回合同伴少）主导宽度，MC 次数不是主因。这与 P3-T0「按场面重采样」的 12–14 点不可直接比；P3 退出标准（中位≤15）需在 P3-T3 用正式引擎与更大 B 再核。

## 3. E1（Q-015）迭代次数

| 档位 | \|ΔQ\| p95（点） | Spearman(S) | 相对基线中位宽增量 | 通过 | 墙钟 |
| ---: | ---: | ---: | ---: | :---: | ---: |
| 250 | 4.55 | 0.9999 | 0 | 否 | ≈159 s |
| **500** | **0** | **0.9999** | **0** | **是** | ≈259 s |
| 1000 | 0 | 1.0000 | 0 | 是 | ≈454 s |
| 2000 | 0 | 1.0000 | 0 | 是 | ≈739 s |
| 4000（基线） | — | — | — | — | （P3-T0 ≈1523 s） |

真值子集：随机 300 对 @20000 次 vs 4000 次，\|Δs\| p95≈0.009、均值≈0.0018——4000 已贴近更高次数；降到 500 主要省成本。

**选定 500。** 若实现上希望多留余量，1000 仍满足判据且 mean \|ΔQ\| 更低，但按 §3.8「最小通过档」取 500。

## 4. E2 面板上限 K

相对全面板（24 局）的 \|ΔQ\| p95：

| K | p95（点） | 通过 |
| ---: | ---: | :---: |
| 10 | 11.8 | 否 |
| 15 | 7.1 | 否 |
| 20 | 5.0 | 否 |
| 30 | 0（≡全部） | 是 |
| 全部 | 0 | 是 |

**选定 K=30。** 本批局数 <30，截断尚未生效；池超过 30 局后按「最早入池 30 局」封顶。K=20 距阈值仅一步之遥，不放宽判据。

## 5. E3 \(G_\text{min}\) / turn±1 / \(w_\text{relax}\)

t4–t10 共 158 个 Player 候选；参照局数降到 G∈{4,6,8,12}，每档重复 50 次；与全量 L0 比 \|ΔQ\|。

| G | 中位误差（点） | p95 | 中位≤10 |
| ---: | ---: | ---: | :---: |
| 4 | 11.4 | 36.9 | 否 |
| **6** | **9.1** | 28.8 | **是** |
| 8 | 7.5 | 25.0 | 是 |
| 12 | 5.3 | 17.4 | 是 |

turn±1 额外 17942 对（500 次）并入后，在 G=6 上扫 \(w_\text{relax}\)：

| \(w\) | 中位误差（点） | 相对 L0 中位误差差 |
| ---: | ---: | ---: |
| **0.25** | **8.44** | **−0.48**（更好） |
| 0.5 | 8.50 | ≈0 |
| 1.0 | 9.09 | ≈0 |

**选定 \(G_\text{min}=6\)，启用 L1，\(w_\text{relax}=0.25\)。** L1 改善幅度不大，但方向一致且满足「不比 L0 差才启用」的反面条件（确实略好）。

## 6. E5（Q-016）跨版本 L2

1.85 候选 × 1.81.2 同回合参照（双方场面），用 **1.85.0 DLL** 模拟 10016 对（500 次）；与纯 1.85 循环赛分位比：

| 指标 | 值 |
| --- | ---: |
| \|ΔQ\| p50 | 0 |
| \|ΔQ\| p95 | **13.6** |
| \|ΔQ\| max | 35.7 |
| 阈值（≤5） | **未通过 → L2 关闭** |

与 Q-011「跨版本五率会偏」一致：冷启动期应显示 `insufficient`，不把上一 BB 版本场面并入参照。

## 7. 对成本与退出标准的含义

- 迭代 500 vs 4000：批跑墙钟约降到 **1/4–1/6**（本机 10552 对：259 s vs 历史 ~1523 s）。
- 面板 K=30：满面板后每局增量成本封顶（方案 §3.5）。
- 聚类 bootstrap 中位宽本校准样本上偏大（≈36 点）——**不据此改默认迭代**；P3-T3 需用正式留一局实现与 B=1000 复核退出标准第 1 条，必要时靠更多局数或 L1 收窄。

## 8. 复现

```powershell
python spikes\strength-cross\tools\calibrate.py --all `
  --baseline spikes\strength-cross\out_both `
  --out spikes\strength-cross\out_calibrate `
  --sim-iterations 500
# 仅重算分析：加 --skip-sim
```
