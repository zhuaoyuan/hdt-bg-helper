# ADR-0005：以本机安装的修改版 HDT 作为实测与验证环境

- **状态：** accepted（所有者 2026-09-25 对话确认）
- **日期：** 2026-09-25
- **相关：** Q-002、Q-004、Q-010、P2-T5，`facts/local-environment.md`

## 背景

- 事实基线是上游源码 v1.58.3 / `509bb0b9`（`facts/hdt-baseline.md`）。
- 所有者机器上实际运行的是 HDT 1.58.1 的一个修改版，日志里有上游源码中没有的输出（`facts/local-environment.md`）。
- 插件原型、日志对照、往返验证都要在真实 HDT 里跑。修改版的内部字段和日志格式可能和源码不同。

## 决定

- 实测和验证以所有者正在使用的修改版 HDT 为准，不另装官方版。
- 源码分析仍以上游基线为准。
- 凡是依赖运行时行为的结论（反射访问内部字段、日志格式、战斗中更新时机），都要写明是在哪个 HDT 版本上得出的。和源码对不上的地方，记到 Q-010。

## 考虑过的方案

| 方案 | 为什么没选 / 为什么选 |
| --- | --- |
| 另装官方 1.58.3，与修改版并存 | 结论与源码一致，但所有者要多维护一套环境，而且日常对局不会用它 |
| 直接换成官方版 | 所有者要放弃修改版的功能 |
| **继续用修改版，结论标注适用范围** | 选中：数据就来自所有者日常对局，不增加负担 |

## 后果

- 正面：采集到的就是所有者真实使用环境下的数据。
- 代价：运行时结论可能不适用于官方版；如果修改版改动了 `BobsBuddyInvoker`，反射路径和日志对照都可能与源码分析不一致。
- 需要跟进：尽早弄清修改版的改动范围（Q-010），至少对比 `BobsBuddyInvoker` 相关的日志输出与源码是否一致。

## 推翻条件

- 修改版改动了插件接口或 Bob's Buddy 调用链，导致源码分析的结论无法在实测中复现；
- 或者本项目打算分发给其他用户使用官方 HDT。
