# ADR-0017：最后 3 场对名次，其余回合对平均掉血

- **状态：** accepted（所有者 2026-10-11 对话确认）
- **日期：** 2026-10-11
- **相关：** ADR-0016（取代其中的选点目标）、`design/R-score-policy-search.md` §3.2–§3.3

## 背景

ADR-0016 用「有名次局的最后 3 场分位 ↔ 最终名次」选择权重。最后 3 场以外的回合几乎不进入这个目标。所有者要求简化：那些回合只看保血——战力高，则对所有同阶段阵容模拟时的平均掉血低。两种目标都会覆盖到的，是最后 3 场里的那些回合，需要合成一个数再选点。

## 决定

1. **平均掉血** \(B(x)\)：场面 \(x\) 对同回合参照对手各模拟，己方受到的英雄伤害的期望（胜和平记 0），再对这些对手取平均。按回合内排名，不把不同回合的原始伤害放在一起比。这是模拟结果，不是下一场真实掉血。
2. **最后 3 场以外的己方场面**（含没有名次的局的全部场面）：只最大化 \(\rho(Q,\,u)\)，其中 \(u\) 是 \(B\) 在同回合里的保血分位（掉血越低 \(u\) 越高）。
3. **最后 3 场的场面**（含淘汰战；第 1 名为终局最后 3 场）：每个场面一个综合标签
   \[
   y = \tfrac{1}{2} v + \tfrac{1}{2} u
   \]
   \(v\) 是该局名次的分位（第 1 名最高），同一局的 3 场共用一个 \(v\)；\(u\) 仍是同回合保血分位。重叠回合上最大化 \(\rho(Q,\,y)\)。
4. 选点目标是两段相关按场面数加权的平均。最高者替换战力（沿用 ADR-0016：名次局少于 12 也替换）。旧的「只对名次」和「用真实下一回合血量做对照」不再作为选点或必出表。

## 考虑过的方案

| 方案 | 为什么没选 |
| --- | --- |
| 两段相关直接相加、不看场面数 | 最后 3 场的局数远少于其余场面，名次目标会被淹没或反过来淹没保血 |
| 重叠回合先比名次、保血只作平局决胜 | 所有者要求两种目标综合，而不是一个当附注 |
| 用真实战斗的掉血代替 \(B\) | 与「对所有同阶段阵容」不符；真实对战只有一个对手 |

## 后果

- 正面：没有名次的局也能进入保血这一段；最后 3 场同时拉开名次和掉血。
- 代价：\(B\) 来自同一批模拟。伤害系数越大，\(Q\) 越像 \(-B\)，保血相关会偏爱大的受伤权重。名次那一半是用来拦住「全程只优化掉血」的。T5 及以前各网格点的 \(Q\) 相同，这段保血相关不改变选点。
- 跟进：\(B\) 依赖伤害分布（Q-020）。分布被上限截断时，保血标签不可用，选点退回只看最后 3 场对名次。

## 推翻条件

综合标签里名次和保血各一半，若替换后的分位在最后 3 场上对名次的相关明显低于「只对名次」的最佳点，把一半一半改成可调权重，而不是改回只看名次。
