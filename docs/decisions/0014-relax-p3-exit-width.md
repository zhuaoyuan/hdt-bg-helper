# ADR-0014：P3 退出标准第 1 条按聚类 bootstrap 实测放宽宽度门槛

- **状态：** accepted（所有者 2026-10-05 对话拍板放宽宽度门槛）
- **日期：** 2026-10-05
- **相关：** `design/P3-T1-strength-engine.md` §5、`facts/strength-percentile-p3t3.md`、`facts/strength-calibration.md`、ADR-0011

## 背景

原 P3 退出标准第 1 条要求：回合 ≤12 的己方 `ready` 场面，聚类 bootstrap 95% 区间宽度**中位 ≤15**，且 **≥80% ≤20** 百分位点。该数字来自方案阶段对「可用宽度」的期望，部分对照曾用 P3-T0「按场面重采样」的 12–14 点，与正式「按局聚类 + MC」不可直接比。

P3-T3 在 BB 1.85 / 30 局 / 329 场面、B=1000 上实测：中位宽 **23.53**，≤20 占比仅 **25.2%**，p80 ≈27.8。校准期同方法更宽（≈36）。宽度由同回合同伴离散主导，提高 `iterations` 几乎无效。继续坚持 ≤15/≤20 会把阶段卡在「攒局到不确定何时」，而引擎交付物与分位语义已可用。

## 决定

将 **P3 退出标准第 1 条** 修订为（其余两条不变）：

1. 当前主版本队列（≥20 局）中，回合 ≤12 的己方 `ready` 场面：聚类 bootstrap 95% 区间宽度**中位 ≤25** 百分位点；
2. 且 **≥80%** 的场面宽度 **≤30** 百分位点。

产品行内 `wide` 标签仍以宽度 **>20** 标注（提示「相对偏宽」），与阶段退出门槛解耦。

## 考虑过的方案

| 方案 | 优点 | 缺点 | 为什么没选 / 为什么选 |
| --- | --- | --- | --- |
| 坚持 ≤15 / ≤20，继续攒局 | 区间更紧才过关 | 可能长期不过；与聚类 bootstrap 现实脱节 | 没选（所有者拍板放宽） |
| **改为 ≤25 / ≤80%≤30** | 对齐 T3 实测（中位 23.5、p80≈28）并留余量；可推进 T4 | 接受更宽的分位不确定度文案 | **选中** |
| 取消宽度退出条 | 不挡路 | 失去「分位是否钉得住」的阶段闸 | 没选 |

## 后果

- 正面：P3 阶段闸与正式不确定度定义一致；当前 1.85 队列可通过第 1 条；T4/T5 不再被宽度卡死。
- 代价：UI/复盘上多数场面仍会带 `wide`（>20）；用户需理解区间常跨二十多个百分位点。
- 跟进：`exit-width` 默认门槛与 `roadmap` / 事实文档同步；用新门槛复跑确认 `ok`。

## 推翻条件

- 局数明显增大（例如同回合参照长期 ≥40–50 局）后中位宽已稳定 ≤15，且产品需要更紧文案；或
- P3-T4 显示在现宽度下分位对名次/血量无可用区分，必须先收窄区间再谈有效性。
