# ADR-0011：战力分位采用"同版本同回合、留一局循环赛 + 确定性参照面板"

- **状态：** proposed
- **日期：** 2026-10-05
- **相关：** ADR-0003（细化其"参照池 / 排序群体 / 权重"，不改指标定义）、`design/P3-T1-strength-engine.md`、`facts/strength-cross-p3t0.md`、Q-008、Q-011、Q-015、Q-016

## 背景

ADR-0003 定义了 \(S(x)\) 和"在同一参照群体里排序"，但没有规定：参照群体怎么取、各成员的 \(S\) 对着谁算、样本不足时怎么放宽、成本怎么控制。P3-T0 的 spike 让每个同组成员各对自己的参照集打分，排序不严格可比；而全量两两对战的成本会随局数线性增长。

## 决定

1. **分桶键 = BB 版本 + 回合。** 可用种族、伤害上限、畸变只作协变量。模拟时用候选方的大厅规则作外壳。
2. **参照群体 = 桶内除候选所在局以外的全部 `ready` 场面**，包括己方和非幽灵对手两侧，保留"只用己方"开关。
3. **分位 = 留一局循环赛排名：** 候选和每个同组成员对着同一个对手集（只排除各自所在的局）计算 \(S\)，再取加权经验 CDF（平局计一半）。
4. **对手集 = 确定性参照面板：** 每个桶最多 K 局（K 由校准实验 E2 确定）。面板满了以后，新局只作为同组成员加入。这样每局的增量成本固定。
5. **放宽阶梯：** L0 同回合 → L1 并入 t±1（降权）→ L2 跨上一 BB 版本（默认关闭，取决于 Q-016）→ `insufficient`。每行输出都写明所用级别。
6. **置信区间 = 按局聚类 bootstrap + 蒙特卡洛噪声。**
7. 每个方向单独模拟，不利用 \(s(a,b)\approx1-s(b,a)\) 来省成本。

## 考虑过的方案

| 方案 | 优点 | 缺点 | 为什么没选 / 为什么选 |
| --- | --- | --- | --- |
| P3-T0 做法（成员各对自己的参照集） | 实现简单 | 参照集不一致，排名不严格可比 | 没选 |
| 全量循环赛，不设面板上限 | 用满全部数据 | 每局成本 ∝ N，约 50 局/版本时超预算 | 没选（K 取"全部"时就是它） |
| **循环赛 + 确定性面板** | 可比、成本固定、缓存友好 | 面板会老化，需要按时间均匀抽样来缓解 | **选中** |
| Bradley–Terry / Elo 拟合 | 能处理稀疏矩阵 | 假设强弱可传递，而阵容之间有克制循环 | 没选；面板变稀疏时再评估 |
| 利用反对称减半 | 成本 ×0.5 | 2.8% 的对偏差 >0.05 | 没选 |

## 后果

- 正面：分位语义清晰（"把 x 放进同版本同回合的历史群体里打循环赛，它排第几"）；增量成本可预测；缓存可以跨任务复用。
- 代价：要维护面板和 `assemblerVersion`；新版本冷启动期会出现 `insufficient`。
- 跟进：E1–E5 校准（`design/P3-T1-strength-engine.md` §3.8）；P3-T2 / P3-T3 实现；P3-T4 验证有效性。

## 推翻条件

- E2 显示任何可接受的 K 都和全量结果偏差过大（|ΔQ| p95 >3 个百分位点），而全量成本又超预算；或者
- P3-T4 显示按 BB 版本分桶导致可用样本长期不足，必须改为按补丁合并分桶。
