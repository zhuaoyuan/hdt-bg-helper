# ADR-0019：平权形状只在单调下降的少数曲线里搜，中段看保血、末段名次作约束

- **状态：** accepted（所有者 2026-10-11 对话确认选点：中段保血为主目标，最后 3 场对局末名次为约束。方案：`design/R-score-policy-search-v2.md`）
- **日期：** 2026-10-11
- **相关：** ADR-0016（保留前期平权为 1 与地板 0.6）、ADR-0017（本 ADR 取代其选点）、ADR-0018（覆盖分位文件仍须过门；门的定义改由本 ADR 规定）

## 背景

ADR-0017 用最后 3 场的综合标签选点；Q-020 之后没有可用的未截断伤害，选点退回最后 3 场分位对名次。2026-10-11 在这个目标上搜 \(t_1\in\{9,12,15\}\)：三条曲线的 Spearman 为 0.383、0.382、0.387，基线 0.381。最后 3 场大多已经落在地板 0.6 上，改变下降方式并不会进入这个目标。

## 决定

1. 平权仍从第 5 回合及以前的 1 单调降到 0.6，不低于 0.6。不按回合自由设权。形状只搜 `design/R-score-policy-search-v2.md` §3.2 的 10 条：一段线性、一次跳变、两段线性。
2. 选点的主目标是回合 6–14 的分位对同回合模拟保血分位。最后 3 场对局末名次的相关是约束：拟合半里低于基线的曲线丢掉。名次用局末 `PLAYER_LEADERBOARD_PLACE`。
3. 局按时间对半。前一半挑选，后一半确认。确认半上中段相关的提升点估计须 \(\ge 0.05\)，且末段名次相关不低于基线，才采用。不过门则不替换 `strength.jsonl`。上一轮 \(t_1=15\) 高出基线 0.006 的结果作废，不视为采用。
4. 只有平权曲线被采用之后，才在 \(t>5\) 搜索一个受到伤害系数 \(\beta\in\{0,0.05,0.10\}\)。贴在伤害上限上的败局不把上限当成精确伤害大小。不搜造成伤害。

## 考虑过的方案

| 方案 | 为什么没选 |
| --- | --- |
| 维持 ADR-0017，只加更多 \(t_1\) | 最后 3 场看不到曲线之间的差别 |
| 每个回合一个权重，或每段各用不同公式 | 确认半的局数撑不住 |
| 确认门要求 bootstrap 区间下界大于 0 | 确认半约二十几局，区间宽到预先定下的 0.05 提升也过不了 |

## 后果

- 正面：下降方式只有在第 6–14 回合才会被分开；0.006 这种差距不能再换成活的战力。
- 代价：中段保血要先有败局伤害摘要，可能要重放已有配对。第一阶段的 \(s\) 仍只用胜平负。
- 跟进：接受本 ADR 之后按方案第 7 节实现。未接受前不改引擎。

## 推翻条件

确认半约二十几局仍无法让 0.05 的提升在区间上站稳，并且所有者要求改用「区间下界大于 0」或改回只看最后 3 场。那时重开本 ADR，而不是把没过门的曲线写进 `strength.jsonl`。
