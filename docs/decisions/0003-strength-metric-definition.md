# ADR-0003：以"本回合战力分位"作为核心战力指标

- **状态：** accepted（所有者在早期讨论 Q3 中确认方向；A3 给出的定义作为初版）
- **日期：** 2026-09-25
- **相关：** P3、`context/early_discussion.md`（Q2、Q3、A3）

## 背景

酒馆战棋变量极多，个人数据量有限，直接做特征工程或端到端学习不现实。所有者提出把底层框架压缩到"战力"一个维度，并否定了以下候选：

- 阵容完整度：静态，现实情况比预设模板繁杂；
- 当前战斗强度：是事后结果，价值低于战斗前评估；
- 未来 1–3 回合成长率：太远，不如直接评估当回合的经济能力（作为以后的独立信号）。

## 决定

核心指标为**本回合战力分位**：

1. 对场面 x，从同条件的历史参照池中取场面 b_i，用模拟器模拟 x 对 b_i，得到胜 / 平 / 负概率。
2. 得分 \( S(x) = \frac{\sum_i w_i \left(P(\text{win}\mid x,b_i) + 0.5\,P(\text{tie}\mid x,b_i)\right)}{\sum_i w_i} \)，其中 \( w_i \) 是参照权重。
3. 把 S(x) 放到同一参照群体里排序，得到分位。
4. 同时输出，但不合并到主分数里：预期承伤、被打死概率、蒙特卡洛误差、参照样本量与匹配条件。

约束：

- 只用 `ready` 快照；样本不足时显示"不稳定"或明确标注放宽了哪些条件，不悄悄补齐。
- 候选场面不进入自己的参照池；训练 / 验证按整局切分。
- 分位是**相对于参照玩家群体**的实战定位，不是阵容的"固有战力"。
- 经济能力不掺进战力分位。

## 考虑过的方案

| 方案 | 为什么没选 |
| --- | --- |
| 手工公式（身材、关键词加权） | 无法跟随版本机制变化 |
| 阵容模板完整度 | 所有者判断为过于静态 |
| 战后实际结果 | 事后信息，单场随机性大 |

## 后果

- 正面：定义本身对版本变化自适应；结果可解释、可复算。
- 代价：计算量大，需要缓存、抽样和状态去重（P3 设计）；强依赖采集完整性和模拟器质量。
- 跟进：P3-T1 细化参照池选择、放宽规则和权重。

## 推翻条件

P3-T4 的有效性评估显示该指标在同一上下文下区分度或稳定性不足。
