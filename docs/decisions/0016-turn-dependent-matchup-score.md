# ADR-0016：对战得分改为随回合变化，并替换默认战力

- **状态：** accepted（所有者 2026-10-11 对话确认：完全替换当前战力计算；平权地板 0.6；最后 3 场含淘汰战）。**选点目标被 ADR-0017 取代。覆盖现行分位文件的时机被 ADR-0018 取代**（搜索完成且有效之后才替换）。
- **日期：** 2026-10-11
- **相关：** ADR-0003（得分公式被本 ADR 取代；分位仍是核心指标）、ADR-0011、`design/R-score-policy-search.md`

## 背景

ADR-0003 把一对场面的得分定为 \(P(\text{win})+0.5\,P(\text{tie})\)。所有者要求更看重保血：同样不败时，高平局应高于「胜率更高但会输」的场面。例子 \(0.2/0.8/0\) 对 \(0.6/0.1/0.3\) 在 0.5 的平权下是 0.60 对 0.65，后者略高。平权大于约 0.57 时前者才更高。

后期还要把胜时造成的伤害、败时受到的伤害算进去，权重随回合上升。具体系数用有名次局的最后 3 场分位对最终名次搜索。所有者要求搜到的公式直接作为唯一的战力计算，而不是和旧公式并列、等样本够了再换。

## 决定

1. 引擎、复盘里对外的 \(S\) / 分位只使用新得分。旧的 \(P_w+0.5P_t\) 只出现在搜索对照表里，不再写进 `strength.jsonl`。
2. 胜权为 1，负的胜平负项权为 0。平权在 T5 及以前为 1，之后线性降到 **0.6** 并不再下降。降到 0.6 的回合、伤害从哪一回合开始、伤害升满要几个回合、胜时伤害与败时受伤的系数，由 `design/R-score-policy-search.md` 的网格在现有有名次局上取最后 3 场分位相关最高的点。名次局少于 12 也采用该点，并在事实文档里写明局数和区间；凑到 12 局后再搜一次。
3. 局级搜索标签：己方最后 3 场战斗的分位均值，**包含**淘汰那一战；第 1 名用终局最后 3 场。循环赛、留一局、参照面板不变。
4. T5 及以前的公式在整个网格里相同（平权 1、伤害权重 0）。最后 3 场目标调不到这些回合。搜索报告必须另给逐回合对照（方案 §3.5）；对照不好不阻止本次替换，只作为下次要不要放开 T5 锁的证据。

## 考虑过的方案

| 方案 | 为什么没选 |
| --- | --- |
| 新旧公式并列，样本不足就不换默认 | 所有者明确要求直接替换 |
| 平权地板 0.5（不超过旧的 1/0.5） | 地板回到 0.5 时，动机例子在后期又会偏向高胜率场面；所有者把地板定为 0.6 |
| 只用最后 3 场，不看前期 | 前期战力会被搜参过程看不见；保留为必出的对照，但不改主目标 |

## 后果

- 正面：保血约束在任何回合都成立（平权 ≥ 0.6）；对外只有一套分位。
- 代价：有名次的局很少时，网格最高点不稳定，早期回合的分位会先被换成「平权 = 1」，而这次搜索并不能证明这个换法更好。伤害项依赖 Q-020；若伤害被上限截断，替换仍然发生，只是伤害系数为 0。
- 跟进：实现时按方案写逐回合名次相关和下一回合血量相关。新 \(s\) 的方差不再用 \(s(1-s)/n\)。

## 推翻条件

逐回合对照里，T5 及以前的分位与名次、与下一回合血量方向相反且样本不少于 12 局；或凑满 12 局有名次的对局后重搜，留出部分明显差于旧公式。出现这些情况时重开前期平权是否锁死为 1，而不是自动改回 0.5。
