# ADR-0018：原始对战数据复用，依赖战力分的 P3 产物等新引擎有效后再重做

- **状态：** accepted（所有者 2026-10-11 对话确认）
- **日期：** 2026-10-11
- **相关：** ADR-0016（取代其中「搜完即覆盖 `strength.jsonl`」的时机）、ADR-0017、ADR-0014、`design/R-score-policy-search.md`

## 背景

新对战得分会改掉由旧的 \(P_w+0.5P_t\) 算出的分位。P3 里已经交付的分位文件、区间宽度、有效性评估和复盘页上的分位，都绑在旧得分上。配对模拟的胜平负次数、标准层和诊断记录并不绑在这个公式上。

## 决定

1. **复用：** 诊断记录、标准层、场面 Input、`pairs` 里已有的胜/平/负次数、`matchups`、参照池与面板。Q-020 通过时只为伤害分位补列，不推翻已有胜平负。
2. **搜索完成 ≠ 有效。** 网格结果写到旁路（参数表，以及可选的候选分位文件），不覆盖现行 `data/strength/1.85.0.0/strength.jsonl`，也不改写 P3-T4 事实里的结论。
3. **有效**须同时满足：采用点的 \(J\) 高于旧公式在同一 \(J\) 上的基线；有平均掉血时 \(\rho_{\text{out}}>0\)，否则最后 3 场分位对 \(-\text{placement}\) 的相关为正且不低于基线；有名次的局不少于 12。缺一则停止，不重做下面第 4 条。
4. **有效之后才重做**这些依赖战力分的产物：用新得分替换 `strength.jsonl`（旧文件留备份）；为新 \(s\) 估计方差后重测退出标准第 1 条，在此之前不把 ADR-0014 的「已通过」算到新分位上；用新分位重跑退出标准第 3 条（局均分位对名次、对下一回合血量、相对 HDT 的名次增量）——这与选点用的 \(J\) 不是同一指标；重生成展示分位的复盘页。然后把路线图 P3 目标句改为分位见 ADR-0003、得分见 ADR-0016。
5. **有效之后也不重做：** P3-T6 阵容图、采集与标准层、参照池结构。T1 的 E1–E5 数字不再当作新得分的证据；本次不重搜 \(G_\min\)、面板大小和迭代次数。新分位若通不过退出第 1 条，再另开是否重校准。

## 考虑过的方案

| 方案 | 为什么没选 |
| --- | --- |
| 搜完立刻覆盖分位并重做 T4/T5 | 参数尚未有效时，会把已经判定过的 P3 结果换成一份还不能用的分位 |
| 连胜平负缓存也推倒重模拟 | 得分是缓存之上的计算，胜平负次数与公式无关 |

## 后果

- 正面：现行复盘和 T4 结论在新引擎无效之前仍然对得上旧分位文件。
- 代价：有效之前仓库里会暂时有两套算法；对外仍只认旧的 `strength.jsonl`。
- 跟进：落地顺序见 `docs/process/prompts/score-policy-search.md`。

## 推翻条件

所有者要求在有效之前就让复盘改读新分位。那时再覆盖 `strength.jsonl`，并把 T3/T4 的旧结论标成已过期。
