# ADR-0009：采集期允许拔线，拔线回合的战果由上下文还原

- **状态：** accepted（所有者 2026-10-05 对话确认："会拔线，请尽可能通过其他上下文数据还原对战结果，不能还原也可以接受"）
- **日期：** 2026-10-05
- **相关：** 取代 ADR-0008 第 4 条"继续避免拔线"；ADR-0008 其余条款不变。`facts/diag-disconnect-completeness-20261005.md`、Q-014、roadmap P2-T3

## 背景

- 团子版的"拔线"会跳过战斗动画，所有者实际经常使用（10-05 一天出现多次）。
- 拔线回合在团子记录里没有实际战果；"直接拔线"回合连阵容和模拟结果都没有，诊断记录也缺该回合的 Combat `Output`。
- P3-T0 要检验战力分位与实际战果的相关性，战果样本越多越好。

## 决定

1. 采集期不要求所有者避免拔线。
2. P2-T3 离线导入对拔线回合按可信度依次尝试还原战果，并给每个战果标注来源（团子文本 / 上下文还原 / 未知）；具体信号源见 Q-014。
3. 无法还原的回合标为战果未知：仍可作为模拟样本（有 Input 时），但不进入"与实际战果相关性"分析。

## 考虑过的方案

| 方案 | 优点 | 缺点 | 为什么没选 / 为什么选 |
| --- | --- | --- | --- |
| 采集期禁止拔线（ADR-0008 原文） | 战果完整 | 改变所有者打法，实际难以坚持 | 所有者不采纳 |
| 拔线回合直接丢弃 | 简单 | 样本损失大且有偏（拔线多发生在特定局面） | 不选 |
| **允许拔线 + 上下文还原 + 标注来源** | 不改打法，尽量保留样本 | 导入逻辑更复杂；还原结果需要验证 | 选中 |

## 后果

- 正面：采集不打扰正常游戏。
- 代价：P2-T3 要实现还原逻辑，并用"有团子战果的回合"验证还原的准确率。
- 跟进：Q-014。

## 推翻条件

- 还原准确率太低，且拔线回合比例高到让 P3-T0 的战果样本不够用。
