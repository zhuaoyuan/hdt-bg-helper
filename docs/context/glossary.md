# 术语表

> 这份文档回答：项目文档里的专有名词是什么意思。新术语第一次出现在文档里时，请补充到这里。

| 术语 | 含义 |
| --- | --- |
| HDT | Hearthstone Deck Tracker，炉石传说开源记牌器，支持以 DLL 形式加载插件 |
| Bob's Buddy（BB） | HDT 内置的酒馆战棋战斗模拟器，闭源 `BobsBuddy.dll`，默认每场战斗模拟 10,000 次 |
| 模拟器输入（`Input`） | Bob's Buddy 的输入对象，包含双方（及双打队友）的场面、英雄技能、任务、饰品、手牌、奥秘、各类计数器，以及大厅级规则 |
| 战斗快照 | 某一回合进入战斗时双方状态的完整记录，是战力评估的基本单位 |
| 战斗中揭示 | 战斗开始后才出现在日志里、会改变模拟器输入的信息（如对手手牌、奥秘、部分附魔）。HDT 遇到这类信息会重新模拟 |
| 模拟就绪状态 | 快照的完整性标签：`ready`（可完整模拟）、`partial`（缺部分上下文）、`unsupported`（含模拟器不支持的内容）、`invalid`（数据冲突或采集异常） |
| 往返验证 | 用采集到的数据重建模拟器输入并运行，与 HDT 当场 Bob's Buddy 的结果对照，用来证明采集是对的 |
| 战力分位 | 本回合战斗前场面与同条件历史参照场面逐一模拟后，其标准化战斗表现超过的参照场面比例。定义见 ADR-0003 |
| 参照池 | 计算战力分位时用作对手的历史快照集合，按模式、补丁、回合、规则等条件筛选 |
| S(x) | 场面 x 对参照池的加权平均得分，胜记 1、平记 0.5 |
| 规则指纹 | 描述一场对局中会改变战斗结果的大厅规则集合（模式、种族池、畸变、伤害上限等），用于判断两个快照是否可比 |
| 畸变（Anomaly） | 酒馆战棋大厅级特殊规则 |
| 饰品（Trinket）、任务（Quest）、目标（Objective） | 酒馆战棋中影响战斗的玩家级对象，都是模拟器输入的一部分 |
| 基线版本 | 事实文档所依据的 HDT 源码版本（当前 v1.58.3 / `509bb0b9`） |
